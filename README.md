# Music Star School

A simple web dashboard prototype for a music school management system.

## Features
- Teacher scheduling and lesson planner
- Director summary for teacher work hours
- Parent invoice creation
- Salary overview for music teachers
- Multi-instrument support for piano, violin, cello, and flute teachers

## Run locally
1. Open a terminal in this folder.
2. Start a local web server:
   python -m http.server 8000
3. Open the browser at:
   http://localhost:8000

## Files
- index.html — app layout
- styles.css — UI styling
- script.js — dashboard data and interactions
